Remember your lines at the board

Knowing a line once isn't the same as finding it in a tournament game. Kiebitz plays your opponent's side and you answer from memory: the whole repertoire, one tricky position, or only the moves you got wrong last time.

  • Find the holes: the common replies you haven't prepared yet.
  • Learn from your games: see exactly where you left your preparation.
  • Your repertoire stays a normal PGN file, with all your notes in it.

Opening it the first time

Kiebitz isn't signed with a paid Apple Developer ID yet, so macOS asks once.

  1. Open the .dmg and drag Kiebitz into Applications.
  2. Right-click Kiebitz in Applications and choose Open.
  3. Click Open again. From then on it opens like any other app.

Blocked anyway? Go to System Settings → Privacy & Security and click Open Anyway.

Or build it yourself

git clone https://github.com/lukas-ott/kiebitz
cd kiebitz
brew install cmake ninja ccache qt
cmake --workflow --preset dev

Questions

Good to know

What does “Kiebitz” mean?

Kiebitz is German for the lapwing, the bird in the icon. A Kiebitz is also the onlooker who stands behind a chess game and comments on every move, the kibitzer. The app is that onlooker, only more helpful.

Is there a Windows or Linux version?

Not for now. Kiebitz is made for the Mac. The chess code underneath doesn't depend on Qt or macOS, so other systems are possible later.

Where are my files?

In your library folder, ~/Documents/Kiebitz unless you choose another one. They're ordinary PGN files you can copy, back up or open anywhere else.

Does it need the internet?

No. Only what you ask for goes online: downloading Stockfish or the puzzle database, the Lichess explorer and cloud engine, and fetching a profile's games.

It's a pre-release. Is it ready?

It's used every day for real preparation, but things still change between versions. Found a bug or missing something? Open an issue on GitHub.
